## Credentials and paid services

Ordinary onboarding connects the local canvas. Supported cloud authoring reuses the host's official Figma connection; it needs no project-operated OAuth backend or second app registration. On 2026-11-06, the actual official `whoami` call succeeded and matched the local REST account. This verifies the current official connection, not every user's first login or every hosted feature. Direct REST, SCIM/Discovery and Embed remain optional and retain their separate credential/app requirements.

The current account is Starter with a View seat. A local 90-day PAT with the available scopes has been created and its real user identity verified. Credentials remain in private local storage. The personal connection is preserved when configuring separate organization/SCIM profiles. A declared organization identity is not labelled a verified user identity, and org-only OAuth does not incorrectly require `getMe`.

Observed server results include an explicit Professional requirement for Webhook creation, a Dev/Full seat plus Organization/Enterprise requirement for hosted Code Connect, unavailable variable/library-analytics scopes, and HTTP 404/per-resource errors for Dev Resources on the QA file. Do not infer successful writes from HTTP 200 when the body has errors, mislabel 404 as a proven plan restriction, or replay a partially applied resource request.

Implementing these clients cannot grant a paid plan, a missing organizational role or an OAuth scope. Keep the actual required connection/permission visible; no fabricated success, account upgrade, billing action, invitation or user provisioning follows from an API audit.

## Ordinary zero-GUI path

Exact file → direct connect → native read/compute/write → persisted property readback → export. Restore the same file/client/profile and keep one stable operation ID. The default profile remains preferred for ordinary editing when the file also has an owned Widget or Dev profile. Two distinct files or two instances of the same profile remain ambiguous. No routine menu opening, screenshot loop, layer clicking or manual connection-code entry is required.

Native success proves native execution. Independent REST readback proves the relevant cloud content, not a global flush. `saveVersionHistoryAsync` is a checkpoint with its own inclusion limitations. Actual focus, dragging, prototype playback and Code Layer input need an interactive acceptance test when required.

## Workflow selection

Use the local create-design/design-system/prototype/motion/FigJam/Slides/design-to-code/Code Connect skills for normal work. Native API discovery returns exact public declarations and task recipes. Use [native profiles](native-profiles.md) for Widget/Dev/Buzz, [cloud APIs](cloud.md) for REST and actual hosted execution, and [embeds](embeds.md) for browser prototype control. Load the corresponding official hosted skill before cloud creation, Specs, Code/Make, shaders or generative plugins. Local mapping authoring does not publish hosted Code Connect, and native shader application does not compile a cloud shader.

Maintenance checks pin and compare the official Plugin/Widget types, REST spec and separate documented service operation/message inventories. New upstream contracts require review and implementation, not an automatic assertion of runtime support.
