# 隐私与访问

插件不包含分析追踪、广告、远程中继、账号服务或预置 API 密钥。本地伴随服务只监听 `127.0.0.1:38491`，其他电脑无法直接连接。Figma 按自身服务和权限管理云端文档；Codex 可能依照其设置，将工具输入和结果发送给模型服务。

## 连接与授权

一次性连接码有效期为五分钟，授权可信本地脚本在一个文件中执行原生 Plugin API。原生凭证不能提交任务或读取其他客户端的数据，MCP 适配器持有独立的私有管理员凭证。授权未续期时在 90 天后过期，会话有效期为八小时。在 Figma 插件界面点击**撤销授权**，会撤销已保存的授权。

Figma 的本地 `clientStorage` 保存授权。文档插件数据中的随机非秘密标识用于重新打开后的本地身份恢复，凭证不会写入设计文档。复制出的标识或相同标题不能建立云文件绑定，每次活跃绑定都需要验证文件 URL。

工作台通过 MCP App 桥接收工具数据，不接收连接凭证或管理员凭证。预览来自 Figma 原生 PNG 导出，localStorage 只保存视图和排序偏好。插件向 Codex 提供设计上下文，不发送用户消息。

## 本地保存什么

安装包、授权、操作记录、账号目录和导出文件保存在 `~/.canvas-bridge/`。`FIGMA_PLUGIN_STATE_DIR` 可以指定隔离的绝对目录。macOS 上目录权限为 0700，私有文件为 0600。伴随服务保存授权哈希，管理员令牌在启动时轮换。

操作结果（回执）可能包含设计数据、文件或页面名称、控制台消息和导出元数据。已完成回执的详情按七天期限或 200 条上限清理；精简的操作标识与终态保留，用于防止重复执行。不确定结果保留至检查和确认完成。执行脚本和参数不会持久化，未使用的输入资源在 24 小时后过期。存在待执行或不确定操作时，不应删除状态目录。

账号目录发现复用 Figma 桌面端的认证环境，不读取钥匙串，也不会把 Cookie 或令牌复制到伴随服务或工作台。连接使用当前用户私有的命名管道，不开放 TCP 调试端口。本地目录保存账号和文件标识、元数据、已验证绑定与覆盖范围。签名缩略图链接带有访问能力，作为私有元数据保存。切换账号会清除前一个账号的目录；扫描不完整时保留已知文件，并记录实际覆盖情况。

## 更新会联网吗

当前用户的 macOS 更新服务在启动时和后台约每小时访问公开 GitHub 发布源，验证发布者签名后安装更新。请求不携带 Figma 凭证、文档数据或执行记录。更新保留私有数据，禁用或卸载插件后，服务在下一次宿主检查时停止。

服务配置位于 `~/Library/LaunchAgents/com.ysun.figma.updates.plist`，更新状态和错误记录位于私有 `updates/` 目录。发行包不包含私有状态、凭证、Git 历史、个人设计或开发记录。
