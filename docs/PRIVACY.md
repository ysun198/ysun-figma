# 隐私与访问

社区调研工具仅返回公开资源的标题、作者、描述、来源、预览与公开统计。请求复用 Figma 桌面端自身的登录会话，不读取或复制 Cookie、钥匙串凭证；服务响应中的令牌、单独的联系字段和账号内部字段不进入工具结果，作者公开描述按资源内容返回。预览只读取资源提供的 Figma 图片 CDN，并校验格式和大小。此能力不复制模板，不购买、点赞、收藏或修改文件。社区内部接口可能变化，许可和收费信息缺失时按未知处理。

插件不包含分析追踪、广告、远程中继、账号服务或预置 API 密钥。本地伴随服务只监听 `127.0.0.1:38491`，其他电脑无法直接连接。Figma 按自身服务和权限管理云端文档；Codex 可能依照其设置，将工具输入和结果发送给模型服务。

## 连接与授权

一次性连接码有效期为五分钟，授权可信本地脚本在一个文件中执行原生 Plugin API。原生凭证不能提交任务或读取其他客户端的数据，MCP 适配器持有独立的私有管理员凭证。授权未续期时在 90 天后过期，会话有效期为八小时。在 Figma 插件界面点击**撤销授权**，会撤销已保存的授权。

Figma 的本地 `clientStorage` 保存授权。文档插件数据中的随机非秘密标识用于重新打开后的本地身份恢复，凭证不会写入设计文档。复制出的标识或相同标题不能建立云文件绑定，每次活跃绑定都需要验证文件 URL。

插件不提供 Codex 内嵌工作台、MCP App 资源或自建聊天界面。账号目录和原生截图通过普通 MCP 工具结果交付，不包含连接凭证或管理员凭证。插件向 Codex 提供设计上下文，不发送用户消息。

## 本地保存什么

安装包、授权、操作记录、账号目录和导出文件保存在 `~/.canvas-bridge/`。`FIGMA_PLUGIN_STATE_DIR` 可以指定隔离的绝对目录。macOS 上目录权限为 0700，私有文件为 0600。伴随服务保存授权哈希，管理员令牌在启动时轮换。

条件写入的快照作为普通只读回执保存所选属性与节点祖先 ID，遵循同一保留期限，不新建任务跟踪库。待执行检查值仅在内存中引用；过期快照需要重新读取。

操作结果（回执）可能包含设计数据、文件或页面名称、控制台消息和导出元数据。已完成回执的详情按七天期限或 200 条上限清理；精简的操作标识与终态保留，用于防止重复执行。不确定结果保留至检查和确认完成。执行脚本和参数不会持久化，未使用的输入资源在最近一次成功上传 24 小时后过期，重复上传相同内容也会刷新期限。存在待执行或不确定操作时，不应删除状态目录。

账号目录发现复用 Figma 桌面端的认证环境，不读取钥匙串，也不会把 Cookie 或令牌复制到伴随服务。连接使用当前用户私有的命名管道，不开放 TCP 调试端口。本地目录保存账号和文件标识、元数据、已验证绑定与覆盖范围。签名缩略图链接带有访问能力，作为私有元数据保存。切换账号会清除前一个账号的目录；扫描不完整时保留已知文件，并记录实际覆盖情况。

Dev 与 Widget 入口使用同一私有状态和授权机制。Widget render 源码是用户信任的本地 JavaScript 模块，保存在私有 widget/definition.js；本机只检查语法，执行发生在 Figma Widget 生命周期内，不从云端状态加载可执行源码。入口 manifest 中的当前用户、活动用户、团队库、支付或其他权限仅使对应 API 可用，不授权购买、邀请、用户管理或其他额外行为。

## 可选云端接口

默认画布操作不需要 REST 令牌。云端创作复用宿主的 Figma 官方连接及其授权流程，本项目不运营公共 OAuth 后端，不集中接收用户令牌。尚未启用的直接 REST、组织服务或 Embed API 不影响本地画布操作，也不作为首次安装的必选授权。

`figma_rest` 只向固定的 `https://api.figma.com` 官方接口路径（包括 v1 与 v2） 发送已授权的普通/组织 API 请求；独立 SCIM 凭据仅用于 `https://www.figma.com/scim/v2/`，并核对配置的租户。拒绝 HTTP 重定向。凭据来自明确配置的环境变量或当前用户拥有的 0600 JSON 文件，不从桌面登录会话中提取。OAuth 刷新凭据原子写回同一私有文件；令牌和客户端 secret 不进入工具参数、结果或操作账本。文件路径配置保存在私有 `rest/` 目录，个人、组织和 SCIM 连接分别保存。组织身份声明和用户 getMe 验证分别标识；接口实际授权由 Figma 验证。

托管 Figma 能力通过插件声明的官方 MCP 和 Figma 已注册连接交给宿主处理，复用宿主已有授权；本地伴随服务不提取该凭据、不自行注册 OAuth 客户端，也不保存第二套托管服务令牌。Figma 的登录、授权和服务权限由实际连接执行。

云端请求和结果会发送给 Figma；按所调用接口可能包含设计、评论、团队或其他已授权数据。云端写入沿用现有操作账本和不确定结果恢复；大结果及图片通过同一受校验导出交付。REST 与托管服务遵循 Figma 各自的权限、套餐和速率限制，日常本地画布操作不依赖它们。

## 更新会联网吗

当前用户的 macOS 更新服务在启动时和后台约每小时访问公开 GitHub 发布源，验证发布者签名后安装更新。请求不携带 Figma 凭证、文档数据或执行记录。更新保留私有数据，禁用或卸载插件后，服务在下一次宿主检查时停止。

服务配置位于 `~/Library/LaunchAgents/com.ysun.figma.updates.plist`，更新状态和错误记录位于私有 `updates/` 目录。发行包不包含私有状态、凭证、Git 历史、个人设计或开发记录。
